optimize-image-folder

写真フォルダを見張って、新しく入った写真を AV1 (AVIF) に自動で変換する常駐ツール。何もしていない間は CPU を一切使いません。

ダウンロード

macOS Apple Silicon / Intel (Universal) ⬇ .tar.gz Windows x64 (Intel / AMD) ⬇ .zip Windows ARM64 (Snapdragon など) ⬇ .zip

リリースノート · SHA256SUMS.txt · すべてのバージョン · ソースコード

元の写真は既定で完全に削除されます。 変換した AVIF を検証し (OS に AVIF デコーダがあれば実際に読み戻して)、元ファイルが変換中に変わっていないことを確かめてから削除します。それでも心配な場合は、インストール時に「ゴミ箱へ移動」か「残す」を選んでください。RAW 形式は変換しません。

インストール

ターミナルに 1 行貼り付けるだけでインストールできます。監視するフォルダ、元ファイルの扱い、既存の写真も変換するかを聞かれます。

ワンライナー (ターミナル)

curl -fsSL https://tsubasatommy.github.io/optimize-image-folder/install.sh | sh

手動でインストールする場合

  1. 上の macOS 版をダウンロードして展開します。
  2. ブラウザで落としたファイルは Gatekeeper に止められるので、隔離属性を外します。 
    xattr -d com.apple.quarantine ./optimize-image-folder
  3. 好きな場所 (例: ~/.local/bin) に置いて、セットアップを実行します。 
    ./optimize-image-folder install

自動起動は ~/Library/LaunchAgents の LaunchAgent として登録されます。

ワンライナー (PowerShell)

irm https://tsubasatommy.github.io/optimize-image-folder/install.ps1 | iex

手動でインストールする場合

  1. お使いの CPU に合った Windows 版をダウンロードして展開します。
  2. 展開したフォルダで PowerShell を開き、セットアップを実行します。 
    .\optimize-image-folder.exe install

自動起動は HKCU\…\Run に登録され、ウィンドウを出さない optimize-image-folder-agent.exe が常駐します。HEIC を変換するには Microsoft Store の「HEIF 画像拡張機能」と「HEVC ビデオ拡張機能」が必要です。

特徴

待機中は CPU 0%

タイマーもポーリングも使いません。OS からファイル変更の通知が届くまで、カーネルの待機状態で眠っています。常駐プロセスのメモリは約 2 MB です。

OS のネイティブ API

Rust から FSEvents・ImageIO (macOS)、ReadDirectoryChangesW・IOCP・WIC (Windows) を直接呼び出します。

変換は使い捨てプロセスで

変換が必要なときだけ低優先度 (Background QoS / EcoQoS) の子プロセスを起動し、終わったら終了します。メモリはすべて OS に返されます。

写真らしさを保つ

EXIF (撮影日時・GPS など)、回転、Display P3 の色域、透過、ファイルの日時を引き継ぎます。

安全な置き換え

AVIF を検証 → 一時ファイルに書いて fsync → rename → 元ファイルが変わっていないか確認、の順に進めてから元ファイルを処理します。

対応形式

JPEG / PNG / HEIC / HEIF / TIFF / BMP / WebP。RAW やアニメーション画像、写真ライブラリ (.photoslibrary) の中身は対象外です。

使い方

コマンド内容
install設定を作り、自動起動に登録して常駐を始めます (--folder --new-only --scan-existing --original delete|trash|keep --yes)
status常駐の状態、設定、監視フォルダにアクセスできるか、最近のログを表示します
convert <パス>ファイルやフォルダを今すぐ変換します (--dry-run で確認だけ)
start / stop / restart常駐の開始・停止・再起動 (設定の変更を反映)
config設定ファイルの場所と内容を表示します
uninstall [--purge]自動起動を解除します。--purge で設定とログも消します

設定ファイル

macOS: ~/Library/Application Support/optimize-image-folder/config.toml / Windows: %APPDATA%\optimize-image-folder\config.toml

folders = ["~/Pictures"]
original = "delete"      # delete | trash | keep
scan_existing = false    # 既存の写真も変換するか
quality = 85             # 1-100
speed = 6                # 1 (高画質・遅い) - 10 (速い)
encoder = "auto"         # auto (=rav1e, 高圧縮) | native (OS, 高速) | rav1e
jobs = 0                 # 同時変換数 (0 = 自動)
settle_seconds = 2       # 書き込みが止まってから変換するまでの秒数
skip_if_larger = true    # AVIF の方が大きければ元ファイルを残す

アンインストール

optimize-image-folder uninstall --purge

そのあと実行ファイルを削除してください (macOS: ~/.local/bin/optimize-image-folder、Windows: %LOCALAPPDATA%\Programs\optimize-image-folder)。
